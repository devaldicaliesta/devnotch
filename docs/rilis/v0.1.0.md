Rilis pertama Notchi: **Island Fase 1** untuk Windows 11.

## Isi rilis

- Island di tengah atas layar dengan perilaku Otomatis, Menempel, dan Sembunyi.
- Kartu media untuk musik dan video, timer, serta status pengisian daya.
- Jendela Pengaturan (`Notchi.exe --settings`).
- Gaya gelap Neumorphism dan Clay 3D.
- Maskot Notchi yang interaktif.
- Lirik tersinkron opsional dari LRCLIB, dengan cadangan dari lyrics.ovh.

Dock dan menu bar belum tersedia; keduanya direncanakan pada Fase 3.

## Unduhan

| Berkas | Isi |
| --- | --- |
| `Notchi-v0.1.0-windows-x64.exe` | Exe portabel, langsung dijalankan tanpa instalasi |
| `Notchi-v0.1.0-windows-x64.zip` | Exe yang sama beserta README dan berkas lisensi |
| `SHA256SUMS.txt` | Checksum SHA-256 untuk memverifikasi unduhan |

## Persyaratan

- Windows 11 22H2 atau lebih baru, x64.
- Tidak perlu hak admin.

## Cara pakai

Jalankan `Notchi.exe`. Notchi berjalan di latar belakang; menjalankannya lagi akan membuka Island.

| Opsi | Fungsi |
| --- | --- |
| `--settings` | Buka jendela Pengaturan |
| `--config-path` | Tampilkan lokasi `config.toml` |
| `--reset-config` | Tulis ulang `config.toml` ke nilai default |
| `--version` | Tampilkan versi |
| `--help` | Tampilkan bantuan |

## Catatan

- Exe ini belum ditandatangani secara digital. SmartScreen bisa menampilkan "Windows melindungi PC Anda"; pilih **Info selengkapnya** lalu **Tetap jalankan**. Jika Smart App Control aktif, Windows memblokir aplikasi yang tidak bertanda tangan.
- Verifikasi unduhan dengan `Get-FileHash .\Notchi-v0.1.0-windows-x64.exe -Algorithm SHA256` dan cocokkan hasilnya dengan `SHA256SUMS.txt`.
